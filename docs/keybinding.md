# Notes de raccourcis VS Code

Petit mémo pour ne pas oublier les raccourcis fréquemment utilisés.

## Raccourcis de folding / code dense

| Action                              | Raccourci            | Commentaire                           |
|------------------------------------|--------------------|--------------------------------------|
| Replier toutes les docstrings       | Ctrl + Alt + A     | Utile pour rendre le code plus dense |
| Déplier toutes les docstrings       | Ctrl + Alt + Z     | Pour revenir à la vue complète       |
| Replier tout le code                 | Ctrl + K, Ctrl + 0 | Collapse all sections                 |
| Déplier tout le code                 | Ctrl + K, Ctrl + J | Expand all sections                   |
| Replier la région sélectionnée       | Ctrl + Shift + [   | Collapse selected block               |
| Déplier la région sélectionnée       | Ctrl + Shift + ]   | Expand selected block                 |

## Navigation & édition

| Action                               | Raccourci            | Commentaire                           |
|-------------------------------------|--------------------|--------------------------------------|
| Aller à la définition                | F12                 | Suivre rapidement le code            |
| Aller à la déclaration               | Ctrl + F12         | Voir où une fonction/variable est définie |
| Ouvrir la palette de commandes       | Ctrl + Shift + P    | Accès rapide aux commandes VS Code   |
| Rechercher dans le fichier           | Ctrl + F            | Recherche rapide dans le fichier     |
| Rechercher dans tout le projet      | Ctrl + Shift + F    | Recherche dans tout le workspace     |
| Remplacer dans le fichier            | Ctrl + H            | Recherche + remplacement             |
| Aller à la ligne                     | Ctrl + G            | Va directement à la ligne souhaitée |
| Basculer commentaire                 | Ctrl + /            | Ligne ou sélection                  |
| Sélection multi-cursor                | Ctrl + Alt + Down/Up| Ajouter un curseur vertical          |
| Sélection rapide identique            | Ctrl + D            | Sélectionner le mot courant + suivant identique |

## Refactoring / Code quality

| Action                               | Raccourci            | Commentaire                           |
|-------------------------------------|--------------------|--------------------------------------|
| Renommer symbole                     | F2                  | Renomme toutes les occurrences       |
| Formater le document                  | Shift + Alt + F     | Black / autopep8 selon setup         |
| Aller à l’import                      | Ctrl + Shift + O    | Liste des fonctions / classes        |
| Organiser les imports                 | Ctrl + Shift + I    | Avec Isort (si configuré)            |
| Fixer les problèmes détectés          | Ctrl + .            | Quick fix / suggestions Pylance       |

## Notes

- Tu peux garder ce fichier ouvert dans VS Code pour un rappel rapide.  
- Ajouter tes propres raccourcis ici pour les rendre “inratables”.
- Les raccourcis peuvent varier selon le OS (Windows / Linux / Mac).
